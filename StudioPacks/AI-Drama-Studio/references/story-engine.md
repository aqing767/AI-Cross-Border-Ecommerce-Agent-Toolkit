# 故事开发与小说改编

## 事实与改编契约

每个输入事实标记为：
- FACT：原著或用户明确提供。
- INFERENCE：从事实合理推断，但原文未明确。
- ASSUMPTION：为起稿暂设，可撤销。
- USER_OVERRIDE：用户明确覆盖此前设定。
- OPEN_ITEM：尚未解决。

改编前创建 source map：原文位置 → 情节节点 → 改编位置 → 保留 / 压缩 / 移动 / 删除理由。关键人物动机、因果、世界规则、伏笔和结局不能无说明地消失。

改编不是逐章机械切集。按冲突单元、情绪转折、信息揭示和自然悬念点分集。章节只作为来源索引，不直接决定集数。

## 项目故事圣经

至少记录：
- logline、类型、受众、平台承诺；
- 世界规则、时间 / 地理 / 势力；
- 主角欲望、恐惧、错误信念、能力和代价；
- 对手目标、资源、学习能力和升级阶梯；
- 关系弧线与不可逆事件；
- 视觉母题、主题、禁改项；
- 未揭示秘密、信息知情范围和揭示顺序。

## 分集结构

每集至少包含：
1. Cold open：从冲突已经发生的时刻进入。
2. Goal：主角本集想完成什么。
3. Pressure：阻碍与代价升级。
4. Turn：信息、权力、关系或目标发生不可逆变化。
5. Payoff：偿还一笔观众期待，或明确延后并增加代价。
6. Cliffhanger：改变观众对下一秒的预测。
7. State delta：本集结束后永久改变的世界状态。

每集设置一个 dominant turn。其他情节服务于它。连载每 3–5 集检查一次 micro-arc 是否闭合并打开更高层问题。

## 剧本验收

- 角色有可见目标和可观察选择。
- 每场戏改变信息、关系、风险或资源至少一项。
- 对白不能重复解释画面已经表达的事实。
- 动作可拍、可表演、可被镜头观察。
- 反转有前置线索，不凭空增加证据。
- 原著覆盖映射可追溯。
- 单集时长通过估算，不为凑时长删掉关键剧情。
- 台词时间线由剧本生成；发现超时先修剧本，再重新生成时间线。
